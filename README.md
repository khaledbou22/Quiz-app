# Quiz-app
An interactive **Quiz Application** that presents multiple-choice questions one at a time, includes a countdown timer, and provides a detailed review of answers at the end of the quiz.
The application manages question flow, user selections, timing, and final results dynamically, delivering a smooth and structured quiz experience through a clean interface.
## ✨ Features
- Multiple-choice questions
- Single-question view with navigation
- Countdown timer with automatic quiz completion
- Answer selection and tracking
- Final score display
- Detailed review of user answers and correct answers
- Responsive and user-friendly layout
